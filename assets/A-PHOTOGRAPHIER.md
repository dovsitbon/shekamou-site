# Photos à prendre sur place

Les photos actuelles viennent de l'Instagram de Shekamou (@shekamoufr), recadrées et triées ici. Les originaux sont dans `assets/raw/` (non publiés).

Pour remplacer ou ajouter une photo : déposez un JPEG (au moins 1600 px de large, lumière naturelle, vue de dessus pour les assiettes et les boissons, aucun visage de client) sous le nom indiqué, puis lancez `npm run media`. L'emplacement dessiné (tasse au trait sur fond pastel) disparaît tout seul.
